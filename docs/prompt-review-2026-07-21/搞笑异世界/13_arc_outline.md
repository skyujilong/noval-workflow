2. 首批开篇例外：首批 1-2 章允许密度稍高（立世界观 / 拉群像 / 布反差公式），但仍须留 1 章做日常闹剧铺陈,避免开局就塞卷级大爆点。**拉群像必须事件驱动**——保留本题材「快速凑齐反差萌小队」的爽感,但每位队友都要由一桩糗事 / 委托 / 冲突 / 误会卷入登场（如被同一场骚乱波及、抢同一个委托、酒馆赊账撞上同桌）,**禁止**写成「这一章就为介绍 X」式挨个自我介绍的登场秀,也**禁止**每章只推一个新队友地排队登场;登场是事件的副产品,不是这一章的目的。
3. 档位错排：禁止连续 2 章以上同属爆发 / 大转折,高潮之间必须插入日常 / 缓冲章让读者喘口气；禁止连续 3 章以上无笑点稀释——本题材主体是闹剧,不是正剧。
4. **日常↔冒险双向夹逼穿插（防止两头塌陷,本次节奏核心）**：
   - **冒险 / 爆点连续 ≤ 2 章** → 第 3 章必须切回日常舞台稀释（回公会分赃 / 回酒馆庆功变吵架 / 回宿舍瘫平复盘）,避免连打不喘;
   - **日常连续 ≤ 3-4 章** → 必须切入一次爆点 / 冒险 / 小转折兑现,避免整批日常空转水剧情（与题材规则「每 7-10 章 ≥1 次爆点章」形成上下夹逼,不是单向下限）。

## 内容创作规则
1. 严守作品既定设定：类型一致、战力体系、物资规则、队伍规矩、人物关系、势力矛盾，不新增私设、不强行降智/拔高角色。
2. 按档位叙事（关键！）：
   - 爆发/转折章：硬冲突、反转、打脸、身份揭晓、大战；情节节点字段写明具体爆点；爽点/虐点/钩子必须落到实处。
   - 推进章：主线小步前进，人物关系/立场/认知有可察觉但不炸裂的变化；允许有小冲突但不抢后续爆发章的戏。
   - 铺垫/缓冲/回落章：承担氛围铺陈、人物日常互动、信息交换、情绪沉淀、伏笔静置发酵、势力态势过渡；核心事件与情节节点字段写“这一章做了什么非事件性的推进”（如两人关系走近半分、主角心境转变、读者获得关键信息），**不要硬塞硬冲突/反转/打脸来凑数**——淡章的价值在于让读者喘息、为下一波蓄势，写得扎实同样重要。
3. 冲突设计循序渐进，支线服务主线，不随意新增无关人物、无关支线，避免剧情散乱。
4. 动作、对话、冲突符合人物性格，角色行为逻辑自洽，保持人设统一；淡章里允许生活化对白、片刻松弛，对话不必句句带刀。
5. 涉及战斗、对峙、逃生场景（仅爆发/转折/部分推进章需要），写明攻防动作、敌我态势，细节具备可落地性；铺垫/缓冲章不强行安排战斗。
6. 物资、伤亡、环境等细节贴合本作世界观设定，逻辑严谨。
7. 人物行动以互动、对话、关系变化为核心，事件推进由角色反应与选择驱动，而非纯外部任务推进。
- 题材聚焦：**（档位配比走 arc_rhythm_override 段，本处只补题材专属风格约束）**

**日常章 4 大内容池（须频繁复用、多池轮换，避免只重复「欠债+打工」两种老梗）等**：
- 小任务闯祸池：小镇零工、公会低阶委托（找猫 / 除鼠 / 送信 / 采药）、临时挑夫 / 帮居民修屋顶 等
- 酒馆日常池：蹭酒赊账、和路人闲聊、斥候露面互动、撞见其他冒险者小队互怼 / 争抢席位、情报黑市 等
- 冒险者公会杂事池：任务张贴板抢单、等级排名榜刷新、招待员冷嘲、赏金分账窗口吵架、讨债窗口躲藏 等
- 宿舍 / 合租日常池：AA 制吵架、洗衣做饭轮值、深夜偷粮、门帘偷听、宿舍暧昧邂逅（走光 / 门缝 / 共浴误闯）等

**日常桥段轮换去重（防水剧情）**：4 大内容池须跨章轮换,同一种日常桥段（欠债 / 蹭酒 / 打工 / 找猫送信）在本批内复用不超过 2 次,措辞不许雷同套话——避免整批读起来像同一件事被水了好几遍。

**冒险条目必须挂主线钩子（反孤立单元剧）**：本批安排的每个冒险 / 爆发 / 大转折的内容节点,都要落到「埋 / 收伏笔、留硬后果（债务 / 道具 / 限制 / 盟友 / 仇家）、或翻转立场 / 势力格局」之一,让冒险的结果改变后续处境、推动主线走向,不许「打完领赏、下一章从头开始」。

**本批冒险须落当前卷档位、且体现爬升（配合 overall_outline 的冒险升级阶梯）**：结合头部【卷位置卡】,本批安排的冒险 / 爆点档位必须落在当前卷允许的档（如卷 2 → T2~T3）,且**不得低于本卷此前已达到的最高档**——已打过地下城（T3）,本批冒险就不许退回清哥布林（T1）当爆点主菜（哥布林只能当日常调剂）;若本批发生升档,升档章 key_turn 须兑现一段主线（阴谋揭层 / 结更高层反派或盟友）。

**战斗质感硬约束**：主线任务章 / 爆发章 / 大转折章的战斗**不许被写薄**——内容节点中至少要能读到具体战斗动作 / 战术选择 / 队友伤亡 / 装备受损 / 战利品分账中的 2 项,写成「顺利击败魔物 / 轻松获胜」式空描述视为塌陷。

**允许失败逃跑作为爆点兑现**：本批规划里可以安排「主角打不过但耍赖逃掉」的爆发章 / 大转折章——撒沙子跑路 / 拿人质谈判 / 装死装晕 / 引开敌人 / 反手栽赃嫁祸——逃跑本身就是主角时刻,不算失败,是本题材反龙傲天的核心爽点之一。禁止把「逃跑」写成「主角怂了没面子」,应写成「耍赖赢了保命且带走情报 / 道具 / 敌方糗事」。

**伤亡尺度上限**：允许写主要角色重伤 / 装备报废 / 临时 KO / 短期昏迷 / 一时能力封印,但**禁止**主要小队成员（卡司≥4 人）真死;已登场过的 NPC 配角允许「下线 / 失踪 / 隐退」式软处理,避免真「死亡」字眼。

**反差萌人设持续暴露**且不同角色轮换（一章内同一角色的怪癖不刷两次）；主角靠信息差 / 耍赖 / 算计赢，**禁止**安排战力跃迁 / 血脉觉醒 / 境界突破式爽点节点；严肃桥段紧跟荒诞稀释章，避免连续 3 章以上无笑点；同时**禁止连续 5 章以上无任何主线兑现 / 爆点**（低烈度日常填充上限,防止节奏塌陷）。

## 格式与文字要求
1. 统一使用上方固定字段排版，段落清晰，字段区分明确，字段 0（本章档位）必须位于最前，不用花哨格式、表情、特殊符号。
2. 文字书面化、精炼化，短句为主，表意精准，不使用网络口水话、情绪化吐槽；淡章的“精炼”指不灌水，不等于把场景一笔带过——人物互动、氛围细节、情绪流动的关键字要写到位。
3. 字数二次自检：单章≤500字，整批合计≤2500，超标自动精简压缩；淡章可更短（300-400字），爆发章可顶到 500字上限。
